Priest.trade takes protocol security and software stability with the highest priority. We welcome responsible disclosures and bug reports from security researchers and community members.

---

## 1. Responsible Security Disclosure

If you discover a potential vulnerability in our smart contracts (`PerpesEngine.sol`, `CounterflowVault.sol`, `PerpesToken.sol`, `PerpesOracle.sol`):

- **Do NOT disclose publicly:** Do not post details on X, public Discord channels, or Telegram groups.
- **Direct Contact:** Send an encrypted email with proof-of-concept steps to:
  `security@priest.trade`
- **What to Include:**
  - Affected contract or service.
  - Step-by-step reproduction steps or Foundry test case.
  - Potential impact assessment.
  - Your Monad address for bug bounty reward consideration.

We commit to reviewing all security reports within 24 hours.

---

## 2. General UI & Application Bug Reports

For non-critical frontend glitches, chart rendering issues, or translation typos:

- Open a ticket in our official Discord server under `#bug-reports`.
- Provide:
  - Browser type and version.
  - Connected wallet type (Privy, Rabby, MetaMask).
  - Screenshots or screen recordings showing the issue.
  - Relevant transaction hashes on MonadVision.
